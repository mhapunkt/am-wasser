# Am Wasser

Deutschsprachige Lernwebseite zur Fischerprüfung in Hessen: 563 Multiple-Choice-Fragen, 27 Lehrbuchlektionen, Quiz, Selbsttest, Suche und Merkliste.

Die Anwendung läuft vollständig im Browser. Lernstände werden lokal gespeichert und können als JSON exportiert werden. Keine Anmeldung, kein Backend, keine externen Skripte.

## Starten

`index.html` im Browser öffnen. Für GitHub Pages den Branch `main` und das Stammverzeichnis `/` als Quelle wählen.

## Grundlage

Bereitgestellter Fragenkatalog: Bund Oktober 2023, Hessen April 2024. Die Erklärungen sind ergänzende Lerntexte. Rechtliche Prüfungsantworten ersetzen keine Prüfung der aktuell geltenden Vorschriften am Gewässer.

Offizielle Quelle: https://landwirtschaft.hessen.de/wasser/fischerei
